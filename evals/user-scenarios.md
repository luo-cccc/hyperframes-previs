# 用户使用回归场景

这是按需执行的回归清单，不是一次已经执行的通过报告。维护本技能或修改适配／保存／导出逻辑时，按改动范围选取相关场景，在隔离项目中执行。不要把合成 DONE/PASS 夹具用于真实制作授权或语义验收。自动检查记录状态与证据，图像/声音范围按实际观察说明。

| 用户请求／情况 | 应观察的结果 |
|---|---|
| 接收已交付 F1/P1/B1，缺真实图片 | 在有效文字身份/身高与资产下做占位预演，不伪称图片已绑定 |
| 有 intake，漏掉 bind；或新建适配项目未设置源 | 明确拒绝演示回退，保留上游母稿 |
| 上游仅推进 next_required、state_seq，或增加其他段 | 本段有效性不变则可复核；不写回上游状态 |
| 本段母稿、预算、原文版本或相关 LOOK/STATE 改变 | 明确要求重新提取/返修，旧回执保留 |
| 共享预算增加另一段，母稿/证据另一 fragment 更新 | 所选范围不变则通过；本段所选内容改变则拒绝 |
| 老文字状态/会话产物 | 实际读取后封存五种证据，不自动猜解析或把草稿提升为 DONE |
| 一镜到底内有三个动作阶段 | 保持一镜；不因阶段数增加切镜 |
| 切点 4.02 秒，24 fps | 拒绝静默舍入；可准确表达的 50 fps 通过，预算不改 |
| S02 改机位未保存，保存 S01／人物关键点 | S02 草稿保持未保存，磁盘不夹带它；导出读取已保存值 |
| 两页先后保存、20 次同时保存 | 只有正确 revision 写入，其余明确冲突/忙；JSON 完整，无 tmp 相互覆盖 |
| 保存路径关键点 | 人物和辅助路径线同步更新；重新载入相同 |
| 人物沿 +X 行走后停步，再非顺序跳转 | 不突然转向 -Z；同时间状态与像素可重复 |
| 另一页改人物颜色/身高/环境几何 | 旧页要求刷新重建，不能假称模型已更新 |
| 改代码重新渲染但保留旧审片 | 四哈希不匹配即 NOT_RUN，不继承旧视频的 CHECKED |
| 导出失败或回执发布失败 | 旧成功视频/回执保留，新失败尝试单独记录 |
| 无人物、无开门事件 | 不补造人物/门动作，UI 隐藏人物面板，返回包正常 |
| 项目外相对来源，移动至中文和空格目录 | bundle 保留关系/原字节，包内可启动；来源注明冻结快照 |
| 跨盘绝对来源 | live 提取可用；portable bundle 明确拒绝不可移动引用，不静默重写 |
| 用户锁定S02后直接调用保存或撤销API | 服务端423拒绝；只有显式解锁后允许，不能绕过UI锁 |
| S01/人物交错编辑再撤销S01 | 仅回退对应camera，不改其他对象；历史after不匹配则拒绝 |
| 路径历史before/after索引或时码被破坏 | INVALID_EDITOR_HISTORY，不写错另一个关键点 |
| 当前镜头套推进/平移模板 | 只预览，保存前不写盘；镜号、起止与母稿保持 |
| 捕获后代码变更但scene文件没变 | 原source token拒绝；旧页面需刷新，不把旧PNG关联新代码 |
| OPEN→RESOLVED→VERIFIED | 处理与验收分离，VERIFIED必需单独证据；stale旧图不可冒充当前验收 |
| 单独交付画面反馈 | 反馈包内PNG与相对图片嵌入可用，原图哈希和来源保留 |
| 只添加锁/撤销历史/批注 | 相同画面证据不无故过期；实质机位/路径改变应过期 |
| requiredActors只列领队 | 不强制其他有意画外角色入镜；代理遮挡警告仍需看图 |

## 战斗、固定骨长与状态恢复

| 用户请求／情况 | 应观察的结果 |
|---|---|
| 接收战斗 JSON 1.1／1.2 | 保留原 unit／shot／beat／keyframe，不伪造 FORMAL、P/B、覆盖或 DONE |
| 六件套原文件为空，或 mapping 指针不存在 | 封存及消费端拒绝，旧证据不覆盖；不能用配对 JSON 模拟声称完成无 JSON 盲转录 |
| 显式 file.md#heading 的未选章节变化 | 原选择不变则只诊断；选中片段变化拒绝，BOM／换行归一化保持相同选择语义 |
| 角色只在后一段登场 | 前段不误加该角色与绑定，后段仍保留它 |
| 原关键状态位于 0.1234567 秒 | 保留精确秒数并独立捕获，MP4 帧索引为空，不舍入到帧网格 |
| 9.5 秒／60fps 的闭端点状态 | MP4 只有 570 帧、末帧 569/60；原 9.5 秒状态另以原前镜 PNG 记录 |
| 手部目标超出臂展或过近 | 固定骨长不变，保留 target_position、真实 position 与 reach_error_m，检查明确报警 |
| 非均匀角色缩放、旋转及接触进入／退出 | 实际网格的世界上臂／前臂长度恒定，不只比较声明值 |
| 非 combat 工程有不可达 handKeys／门目标 | 通用 spatial-check 也给出 ARM_TARGET_UNREACHABLE |
| 手掌伤损与持物同时存在 | surface mark 随实际手腕，不冒充第二件持物，不掩盖真实接触间隙 |
| 资源消耗、幻象退场及光色未来事件后回跳 | 不提前消耗、不残留未来状态；相同时刻状态与像素一致 |
| 自由视图／选中对象时捕获另一镜或未来状态 | 使用原镜闭区间，随后恢复时间、视图、选择、手臂和灯色 |
| 原关键状态与当前执行 cue 互相矛盾 | 明确登记 source_conflicts 和实现取舍，不伪称用户已修改原文 |
| 结构、规格通过但有战斗代理告警 | fight_proxy 为 FAIL、相关 FIGHT_PREVIS 为 BLOCKED，不由手工 review 覆盖 |

每次执行记录实际输入／版本、观察范围、证据和未测项。测试次数不等于独立用户场景数，软件 PASS 不等于完整媒体验收。
