## 复现基础流程

在仓库根目录使用一个尚不存在的输出目录：

```text

cd outputs/60fps-check
npm ci
npm run prepare-libs
npm run validate
npm run lint
npm run spatial-check
npm run render
npm run snapshot
npm run handoff
```
